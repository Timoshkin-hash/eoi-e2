# Методология расчёта задачи №2

## Основная модель

Новые пользователи зависят от текущей базы:

```text
ΔN = g × Nₜ₋₁ = (g / (1 + g)) × Nₜ
```

Поэтому месячная прибыль равна:

```text
П(N) = ARPU × N − Cmaint − CAC × (g / (1 + g)) × N
```

Критическая масса существует только при положительном маржинальном вкладе пользователя:

```text
ARPU − CAC × g/(1+g)/(1+g) > 0
```

При этом условии:

```text
Nкрит = Cmaint / (ARPU − CAC × g/(1+g))
```

Если `ARPU − CAC × g/(1+g)/(1+g) ≤ 0`, сеть не становится самоподдерживающейся простым увеличением базы: переменные затраты привлечения съедают весь ARPU ещё до покрытия затрат на поддержание.

## Траектория пользователей

До критической массы используется `growth_before_critical`, после неё — `growth_after_critical`. Траектория ограничена `market_potential_users`. Начальная база месяца 0 уже существует и не считается новым привлечением.

## Ценность сети

```text
V(N) = k × N²
```

Закон Мэткалфа используется как учебная оценка потенциальной ценности сетевого эффекта, а не как бухгалтерская стоимость компании.

## NPV

Основной NPV строится по фактическим помесячным прибылям:

```text
NPV = Σ Pₜ / (1 + rₘ)^t
```

где `rₘ` — месячная ставка дисконтирования. Для строгого CAC и для отдельного операционного CAC пользовательская траектория и денежные потоки пересчитываются независимо.

## Чувствительность

Пороговые значения ARPU, CAC и темпа роста рассчитываются повторным запуском полной модели: при каждом пробном значении заново определяются критическая масса, пользовательская траектория, новые пользователи, прибыль и NPV. Это предотвращает смешение параметров с уже зафиксированной траекторией.

## Ограничения

Модель не учитывает отток, сезонность, налоги, капитальные затраты, маржу после переменных расходов, различия между зарегистрированными и активными пользователями и изменение CAC при масштабировании. Операционный CAC — отдельная управленческая гипотеза, а не исходное значение задания.
