# Экономика информатизации — решение экзаменационной задачи №2

Репозиторий содержит воспроизводимое решение задачи **«Расчёт критической массы и ценности социальной сети»** для проекта «ГородСоцСеть». Анализ включает критическую массу, динамику пользователей, сетевую ценность по закону Мэткалфа, помесячную прибыль, NPV, сценарный анализ, минимальный ARPU и оценку маркетингового ускорения.

## Содержание

| Путь | Назначение |
|---|---|

## Ключевой вывод

При исходных параметрах `CAC = 500 руб.` и `ARPU = 15 руб.` строгая критическая масса составляет **1 133 333 пользователя**, что превышает потенциал рынка в 1 000 000 человек. Следовательно, исходная модель не становится самоподдерживающейся внутри заданного рынка.

Для стратегического анализа отдельно рассмотрен операционный сценарий со снижением CAC до 50 руб. В нём критическая масса составляет **233 333 пользователя**, но при росте 3% в месяц она достигается примерно за 130 месяцев, то есть значительно позже горизонта расчёта в 36 месяцев. Поэтому проект требует снижения CAC, повышения ARPU и поэтапного запуска.

## Установка и запуск

```bash
git clone https://github.com/Timoshkin-hash/eoi-e2.git
cd eoi-e2
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# Git Bash: source .venv/Scripts/activate
pip install -r requirements.txt
jupyter lab
```

Откройте `notebooks/task_02_social_network.ipynb` и выполните все ячейки. Для безинтерактивного запуска из корневой папки проекта:

```bash
python -m jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=120 notebooks/task_02_social_network.ipynb
```

После выполнения Notebook можно сформировать HTML-отчёт:

```bash
python -m jupyter nbconvert --to html --output-dir reports --output task_02_report notebooks/task_02_social_network.ipynb
```

PDF можно получить из HTML через браузер: открыть `reports/task_02_report.html`, нажать `Ctrl + P`, выбрать «Сохранить в PDF» и сохранить файл как `reports/task_02_report.pdf`.

## Важные допущения

В строгом расчёте CAC умножается на число новых пользователей текущего месяца. Поэтому условие самоподдержания имеет вид `ARPU × N ≥ maintenance + CAC × (growth × N)`. Закон Мэткалфа используется как учебная оценка потенциальной сетевой ценности и не является бухгалтерской стоимостью бизнеса. Дополнительные ограничения включают отсутствие оттока, налогов, капитальных затрат, сезонности и изменения CAC при масштабировании.
